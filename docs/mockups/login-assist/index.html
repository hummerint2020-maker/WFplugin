Login page helpers — mockups (Step 1)

Four small helpers on the app's own login page. One switch in wp-admin → Appearance → Login screen, "Sign-in helpers", off by default: while it is off the page is exactly as today. The fix for an empty form (it now comes back to this page, not wp-login.php) is separate and always on.

The password is never kept anywhere. The username is kept only in this browser tab (sessionStorage) until the sign-in works.
