Leave in My requests — mockups (Step 1)

The owner's idea (2026-11-21): the Leave page is no longer needed. What only it does moves to My requests: a balances strip (every leave type), "Request cancellation" on an approved leave that has not started, the cancellation's states, and a Leave filter with the whole history. Leave and early leave are already asked from New request; managers already decide them in My approvals.

The old Leave page stays behind a switch (wp-admin → Features), shown until it is turned off. Only while My approvals is on.
