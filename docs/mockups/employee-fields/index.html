Employee details for letters — mockups

Three optional fields on an employee for HR letters (owner decision): the name in Arabic, gender and the hiring date. An Arabic letter uses the Arabic name; gender picks "Mr." or "Ms." and the matching wording; the hiring date is the "employed since" date. Left empty, a letter uses the employee name, wording that fits anyone, and the day the employee was added. Edited on the employee profile in wp-admin, in Add Employee, and for many employees at once from a file (preview, then apply). Changes are audited.
