HR letters — mockups

Employees ask HR for a letter from My requests (Money and documents → HR letter): the type from a list or "Other", who it is addressed to, Arabic or English, an optional note. It goes through the HR Letter approval workflow (HR by default; an HR employee's own letter goes to the administrators).

Each type has its delivery: an automatic PDF from the type's template (Amiri font, Arabic-Indic digits, salary in words, Hijri date), a file HR uploads, or request only (HR marks it ready to collect). "Other" always goes to HR to upload. A template with the salary needs Manage Payroll to save; files are private. Off by default.
